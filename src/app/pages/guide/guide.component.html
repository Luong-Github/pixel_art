Getting started

Pixel Art Studio runs entirely in your browser — nothing to install, and your work stays on your device. Open the editor, pick a tool from the left rail, choose a color, and start drawing on the center canvas. Zoom with Ctrl + scroll (or +/−) and pan by holding Space.

  1. Set the canvas size in the Canvas panel (Width × Height).
  2. Draw with the Pen; flood areas with Fill.
  3. Add frames & layers in the Timeline to animate.
  4. Export a PNG, animated GIF, or sprite sheet from Export ▾.

Interface & panels

The workspace is built from dockable panels, like a desktop app. Every panel (Tools, Color & Palette, Display, Canvas, Timeline) can be rearranged:

  • Drag a panel by its title bar to move it between the left, right or bottom dock zones, or reorder it.
  • Tear off a panel by dragging it out of any zone — it becomes a floating window you can move and resize, then drag back to re-dock.
  • Use the header buttons to collapse (▬), float (⧉) or close (✕) a panel.
  • Re-open closed panels from View ▾; restore everything with Reset layout.
  • Your layout is saved automatically and restored next visit.

The top toolbar holds undo/redo, transform, nudge and clipboard icons, plus the File, Export and View menus.

Drawing & dithering

  • Brush size — set in the Canvas panel, or press [ / ].
  • Mirror-X — paints symmetrically across the vertical axis (Shift+M).
  • Grid — toggle the pixel grid with G (auto-hidden when zoomed far out).
  • Dither brush — in Color & Palette, choose 25% / 50% / 75%. The pen then alternates primary & secondary in a pixel-perfect pattern.
  • Selection — use Select to mark a region, then Move, or Copy / Cut / Paste, Rotate, Flip and Nudge it.

Color & palette

  • Primary / Secondary colors — left-click a swatch sets primary, right-click sets secondary. Swap them with X.
  • Pick from screen — the eyedropper buttons sample any on-screen color.
  • Built-in palettes — load PICO-8, Game Boy, NES, DawnBringer 16 or ENDESGA 32 from the dropdown.
  • Save your current palette (kept in the browser) and reload it later.
  • Palette lock — when on (🔒), every stroke snaps to the nearest palette color so you never stray off-palette.

Layers

Layers live in the Timeline’s left column (one row per layer).

  • Add / Duplicate / Delete layers from the timeline toolbar.
  • Reorder by dragging the ⠿ handle, or with the ▲ / ▼ buttons.
  • Visibility (◉/○) and lock (🔒) per layer — a locked layer can’t be drawn on or edited.
  • Rename inline, and set the active layer’s opacity with the slider.
  • Right-click a layer for a context menu — rename, duplicate, new, show/hide, lock/unlock, move up/down or delete.

Animation & timeline

The timeline is a frame × layer grid with thumbnails per frame.

  • Playback — ⏮ ▶ ⏭ with Loop, FPS (applies to all frames) and per-frame ms. Press Enter to play, ,/. to step.
  • Frame ops — Add, Duplicate, Insert before/after, Reverse, and Delete (removes all selected frames).
  • Select frames — click a frame to select it; Shift+click (or Shift-drag) for a range; Ctrl+click to toggle individual frames. Clicking the canvas or empty timeline clears the selection.
  • Move frames — drag a frame header to reposition it; if it’s part of a multi-selection the whole block moves.
  • Copy & paste frames — use the ⧉ / 📋 buttons in the Frame group to copy the selected frames and paste them right after the current frame.
  • Onion skin — shows ghosts of the previous (red) and next (blue) frames; adjust opacity and tint in the Canvas panel.
  • Toggle the layer/frame views from View ▾ in the timeline toolbar.

Import & convert

Turn any image into pixel art via File ▾ → Import / convert image…. The dialog lets you choose:

  • Target size (64 / 96 / 128 or a custom long side) and palette count.
  • Fit (contain / cover / stretch), contrast, sharpen and dithering.
  • Import into the current tab (overwrites, with confirmation) or a new tab.

Export

From Export ▾:

  • PNG at 1× / 2× (free) or 4× / 8× (Pro), with transparency preserved.
  • Animated GIF (Pro) of the visible frames, using each frame’s duration.
  • Sprite sheet (Pro) — grid or single row — plus an engine-ready JSON atlas (frame size, count, durations, columns, pivot).
  • Pivot / anchor — set Center / Feet / Top-left in the Canvas panel; it’s written into the sprite-sheet JSON.

Free exports add a small watermark; Pro removes it and unlocks GIF, sprite sheets and higher scales.

Projects

Use Export Project to save a .pixelart.json file containing all workspaces, frames, layers, palette and settings — then Import Project to continue later. Everything stays local to your machine.
