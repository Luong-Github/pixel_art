Getting started

Pixel Art Studio runs entirely in your browser — nothing to install, and your work stays on your device. Open the editor, pick a tool from the left rail, choose a color, and start drawing on the center canvas. Zoom with Ctrl + scroll (or +/−) and pan by holding Space.

  1. Set the canvas size in the Canvas panel (Width × Height).
  2. Draw with the Pen; flood areas with Fill.
  3. Add frames & layers in the Timeline to animate.
  4. Export a PNG, animated GIF, or sprite sheet from Export ▾.

Interface & panels

The workspace is built from dockable panels, like a desktop app. Every panel (Tools, Color & Palette, Display, Canvas, Timeline) can be rearranged:

  • Drag a panel by its title bar to move it between the left, right or bottom dock zones, or reorder it.
  • Tear off a panel by dragging it out of any zone — it becomes a floating window you can move and resize, then drag back to re-dock.
  • Use the header buttons to collapse (▬), float (⧉) or close (✕) a panel.
  • Re-open closed panels from View ▾; restore everything with Reset layout.
  • Your layout is saved automatically and restored next visit.
  • Command palette — press Ctrl+K to search and run any tool or action.
  • Autosave — your whole project is saved to the browser and restored on reload; File ▾ → Start fresh clears it.
  • Minimap — appears bottom-right when zoomed in; click/drag it to pan. Brush stabilizer (Tools panel) smooths jittery freehand strokes.
  • Colour — File ▾ → Edit → Adjust colours (hue/saturation/brightness), and Recolor sprite (Palette tab) snaps the whole sprite to the current palette.

The top bar keeps only undo/redo and the File, Export and View menus. A selection bar under it holds rotate / flip / copy / cut / paste (they act on the selection, or the whole layer when nothing is selected). The Tools panel is grouped into Draw, Shape and Select, with brush size, pixel-perfect and symmetry options below it.

Drawing & dithering

  • Brush size — set in the Canvas panel, or press [ / ].
  • Symmetry — in the Canvas panel choose Off, Mirror X, Mirror Y, Both (4-way) or Mandala (8-way, square canvas); strokes, fills and shapes mirror live. Shift+M toggles Mirror X.
  • Pixel-perfect — tick Pixel-perfect (Tools panel) so freehand 1px strokes drop redundant L-corners for clean lines, like Aseprite.
  • Gradient tool (D) — drag from the primary to the secondary colour to fill the selection (or whole layer). Choose Linear/Radial and toggle Bayer dither (pixel-art) vs smooth RGB.
  • Shading ink (A) — drag over pixels to step them one shade darker (hold Alt to lighten) along the palette ramp — pair it with the Shadow Ramp palette.
  • Custom brush — select a region, then Brush from selection (Tools panel) to stamp it with the Pen.
  • Outline / Replace color — from File ▾ → Edit: outline the layer in the secondary colour, or replace every secondary-coloured pixel with the primary.
  • Reference image — load a photo overlay (Canvas panel) at adjustable opacity, above or below the art, to trace from. You can also load a Pixel Studio .json export — it's flattened into a crisp, pixel-exact reference (no smoothing). Tiled preview (Preview panel) repeats the sprite 3×3 to check seamless tiling.
  • Timelapse — File ▾ → Timelapse → Record, draw, then Export timelapse (GIF) to share your process. Forgot to record? Export GIF from undo history rebuilds an approximate timelapse from this session's undo steps — but only while the editor tab is still open (it's lost on reload).
  • Grid — toggle the pixel grid with G (auto-hidden when zoomed far out).
  • Dither brush — in Color & Palette, choose 25% / 50% / 75%. The pen then alternates primary & secondary in a pixel-perfect pattern.
  • Selection — mark a region with Select (rectangle), Magic wand (contiguous same-color area) or Lasso (freehand shape), then Move, Copy / Cut / Paste, Rotate, Flip and Nudge it. Hold Shift to add to, or Alt to subtract from, the current selection (wand & lasso).
  • Free transform — with a selection, press T: drag the box handles to scale, the top knob to rotate freely, or inside the box to move. Enter commits, Esc cancels (clicking outside also commits).

Generate (procedural)

The Generate panel fills the active layer with a procedural pattern (Pixel Composer-style) using your primary (and optionally secondary) colour. Every result is undoable, and if a region is selected it's confined to that selection.

  • Noise — smooth value noise; tune Scale (blob size), Density (coverage) and Seed.
  • Gradient (dither) — a Bayer-dithered ramp along Vertical / Horizontal / Diagonal; Density shifts the midpoint.
  • Checker — chequerboard with cell size set by Scale.
  • Bricks — staggered brick wall; mortar lines use the second tone.
  • Stipple — random dots at the chosen Density.

Two colours uses the secondary as the second tone (off = transparent). Replace clears the area first (off = overlay on top). A Seed + 🎲 Random make noise/stipple reproducible. Open the panel from View ▾ if it's hidden.

Color & palette

  • HSV picker — drag the saturation/value square and the hue slider, or type a HEX / R G B value, to set the primary color.
  • Primary / Secondary colors — left-click a swatch sets primary; right-click opens a menu to set it as primary/secondary, edit the colour (native picker, replaces it in place) or remove it from the palette. Swap primary/secondary with X. Recent colors appear above the palette.
  • Palette tools — Sort by hue / brightness, add a primary→secondary Gradient ramp, generate Harmony colours from the primary, build the palette From sprite (its used colours) or From sel (only the colours inside the current selection — handy for grabbing one object's palette).
  • Pick from screen — the eyedropper buttons sample any on-screen color.
  • Built-in palettes — load PICO-8, Game Boy, NES, DawnBringer 16, ENDESGA 32 or the Shadow Ramp (a light→dark shading ramp) from the dropdown.
  • Purpose palettes — ready-made ramps for common subjects, each spanning deep shadow → bright highlight for strong contrast: Water (deep blue → cyan → foam), Tech / Devices (brushed-steel greys + LED accents), Nature (foliage greens + bark + sky/flower pops), and Glass — paint it on a layer (or brush) at reduced opacity so the background shows through for a see-through effect.
  • Save your current palette (kept in the browser) and reload it later.
  • Palette lock — when on (🔒), every stroke snaps to the nearest palette color so you never stray off-palette.

Layers

Layers live in the Timeline’s left column (one row per layer).

  • Add / Duplicate / Delete layers from the timeline toolbar.
  • Selection → new layer — with a selection active, use ⧉ Layer / ✂ Layer on the selection bar (or Ctrl+J to copy, Ctrl+Shift+J to cut) to lift the selected pixels onto a fresh layer above.
  • Reorder by dragging the ⠿ handle, or with the ▲ / ▼ buttons.
  • Visibility (◉/○) and lock (🔒) per layer — a locked layer can’t be drawn on or edited.
  • Rename inline, and set the active layer’s opacity with the slider.
  • Blend mode — pick how the active layer mixes with the layers below from the Blend dropdown in the timeline toolbar: Normal, Multiply, Screen, Overlay, Darken, Lighten, Add or Difference. Try File ▾ → Examples → Blend tree for a worked example (Multiply shadow + Screen highlight + Add glow, grouped).
  • Groups (folders) — press 📁 in the Layer toolbar (or right-click → New group) to wrap the active layer in a folder. A group header row appears with a caret to collapse/expand, plus group visibility, lock and (right-click) opacity, color and rename / ungroup. Hiding, locking or fading a group affects all its layers. Move layers in or out via the layer’s right-click menu. While the active layer is inside a group, the ＋ Add button adds the new layer into that group — to add one outside, right-click the group header and choose ＋ Add layer above group.
  • Right-click a layer for a context menu — rename, duplicate, new, show/hide, lock/unlock, move up/down, group/ungroup or delete.

Animation & timeline

The timeline is a frame × layer grid with thumbnails per frame.

  • Playback — ⏮ ▶ ⏭ with Loop, FPS (applies to all frames) and per-frame ms. Press Enter to play, ,/. to step.
  • Frame ops — Add, Duplicate, Insert before/after, Reverse, and Delete (removes all selected frames).
  • Select frames — click a frame to select it; Shift+click (or Shift-drag) for a range; Ctrl+click to toggle individual frames. Clicking the canvas or empty timeline clears the selection.
  • Move frames — drag a frame header to reposition it; if it’s part of a multi-selection the whole block moves.
  • Copy & paste frames — use the ⧉ / 📋 buttons in the Frame group to copy the selected frames and paste them right after the current frame.
  • Animation tags — select one or more frames and press 🏷 in the Frame group to name that range (e.g. idle, walk, attack). Tags appear as colored bars above the frames. Click a bar to select its range; right-click for options — rename, cycle direction (forward → / reverse ← / ping-pong ↔), change color, set repeat, or delete. Choose a tag in the Play dropdown to loop just that range during playback. Tags are written into the sprite-sheet JSON (frameTags) for your game engine.
  • Onion skin — shows ghosts of the previous (red) and next (blue) frames; adjust opacity and tint in the Canvas panel.
  • Toggle the layer/frame views from View ▾ in the timeline toolbar.

Import & convert

Turn any image into pixel art via File ▾ → Import / convert image…. The dialog lets you choose:

  • Target size (64 / 96 / 128 or a custom long side) and palette count.
  • Fit (contain / cover / stretch), contrast, sharpen and dithering.
  • Import into the current tab (overwrites, with confirmation) or a new tab.

Tilemap

Open the Tilemap panel from View ▾. It slices your current sprite into a grid of tiles, then lets you paint a map with them — great for building levels and reusing tiles.

  • Tile size — pick 8 / 16 / 24 / 32; the sprite is sliced left-to-right, top-to-bottom into that many tiles. Hit ↻ Tiles after editing the sprite to re-slice.
  • Map size — set Cols × Rows and the on-screen Zoom.
  • Paint — pick a tile from the strip, then click / drag on the map. Right-click (or the Erase button) clears cells; Clear empties the map.
  • Auto-tiling — toggle ⊞ Auto to auto-pick edge/corner variants from neighbours. It uses 16 tiles starting at the selected one, ordered by a 4-bit cardinal bitmask (N=1, E=2, S=4, W=8): tile 0 = isolated, tile 15 = fully surrounded. Lay your auto-tile block out in that order, select its first tile, then paint — variants update automatically as you connect cells.
  • Export (Pro) — writes the rendered map PNG, the tileset PNG, and a JSON map (tile size, columns/rows, tileset info and the cell index array) for your engine.

Export

From Export ▾:

  • PNG at 1× / 2× (free) or 4× / 8× (Pro), with transparency preserved.
  • Animated GIF (Pro) at 1× / 2× / 4× / 8× of the visible frames, using each frame’s duration (transparency preserved).
  • Video for social media (Pro) — MP4 (or WebM where MP4 isn’t supported) at 4× / 8×, since many platforms reject GIF. Video has no transparency, so pick a Video background colour first.
  • Sprite sheet (Pro) — grid or single row — plus an engine-ready JSON atlas (frame size, count, durations, columns, pivot and animation tags).
  • Pivot / anchor — set Center / Feet / Top-left in the Canvas panel; it’s written into the sprite-sheet JSON.

Free exports add a small watermark; Pro removes it and unlocks GIF, sprite sheets and higher scales.

Projects

Use Export Project to save a .pixelart.json file containing all workspaces, frames, layers, palette and settings. Bring one back with either Import as tab(s) — adds its workspaces as new tabs, keeping your current ones — or Open Project (replace all) to load it as a fresh session. Everything stays local to your machine.
